# 🐧 Курс консоли Linux — VK Mini App

Интерактивное приложение для обучения работе с консолью Linux. Состоит из 10 видеоуроков, встроенных через виджет VK Video. Данные пользователя загружаются через VK Bridge.


## 📌 Функциональность

- Список из 10 шагов (уроков) с номерами и названиями.
- При клике на шаг открывается встроенное видео с автозапуском.
- Видео встраивается через официальный виджет `vk.com/video_ext.php`.
- Кнопка «Назад к урокам» для возврата к списку.
- Отображение аватара и имени текущего пользователя VK (если запущено в VK Mini App).
- Встроенная отладка (лог-панель) для разработчиков.
- Интеграция с Яндекс.Метрикой для отслеживания событий.

## 🛠 Технологии

- Чистый HTML, CSS и JavaScript (без фреймворков).
- VK Bridge (для работы внутри VK Mini App).
- Яндекс.Метрика (счётчик `110303584`).

## 🚀 Установка и запуск

Проект представляет собой один статический HTML-файл. Для запуска достаточно:

1. Скачать файл `index.html` (или склонировать репозиторий).
2. Открыть его в браузере.

```bash
# Если у вас есть репозиторий
git clone <url-репозитория>
cd <папка-проекта>
# Открыть index.html в браузере
```

Или просто дважды кликнуть по файлу `index.html`.

## ⚙️ Настройка для VK Mini App

Если вы планируете использовать приложение как VK Mini App:

1. Зарегистрируйте приложение в [VK Admin](https://vk.com/apps?act=manage).
2. В настройках приложения укажите **URL** для запуска (например, `https://ваш-хост/index.html`).
3. Убедитесь, что в коде указан корректный `owner_id` группы, где размещены видео (в коде используется `-193665099` — замените на свой, если нужно).
4. Для работы VK Bridge необходимо, чтобы приложение запускалось внутри официального клиента VK (мобильного или веб-версии VK Mini Apps).

## 📖 Использование

1. **Главный экран** — список из 10 уроков с эмодзи.
2. **Выбор урока** — клик по любой строке открывает видео в том же окне.
3. **Просмотр видео** — видео запускается автоматически. Можно переключаться на полноэкранный режим.
4. **Возврат** — кнопка «Назад к урокам» скрывает видео и показывает список.
5. **Отладка** — клик по версии (внизу) открывает панель с логами.

## 🐞 Отладка

- Нажмите на текст **«Версия 2.0.2»** внизу страницы — появится панель с логами.
- Также можно добавить параметр `?debug=true` в URL, чтобы панель была видна сразу.
- Все логи дублируются в консоль браузера.

## 📊 Метрика

В приложение встроен счётчик Яндекс.Метрики (ID `110303584`). При клике на каждый урок отправляется цель `step1` … `step10`. Вы можете заменить ID на свой или удалить блок с метрикой, если он не нужен.

## 📝 Примечания

- Видео доступны только при подключении к интернету (встраиваются через iframe).
- Для корректной работы внутри VK требуется установленное приложение VK или браузер с поддержкой VK Bridge.
- Весь код написан с учётом мобильных устройств (адаптивная вёрстка).
