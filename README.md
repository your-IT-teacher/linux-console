# 🐧 Курс консоли Linux — VK Mini App

Интерактивное приложение для обучения работе с консолью Linux. Состоит из 10 уроков, каждый из которых содержит видео и статьи (в первом уроке – 9 статей). Прогресс пользователя сохраняется в VK Storage (с fallback на localStorage), что позволяет продолжить обучение на любом устройстве.

## 📌 Функциональность

- **Список уроков** – загружается из `course.json`, отображаются номера, названия и статусы (✅ пройден, 📖 изучается).
- **Видеоуроки** – встраиваются через виджет VK Video (автозапуск).
- **Статьи** – встроенный текстовый материал с отслеживанием статусов:
  - 🔵 – новая (не начата)
  - 📖 – изучается (текущая)
  - ✅ – изучена
- **Навигация по статьям** – клик по статье открывает её, кнопка «Следующая статья» отмечает текущую как изученную и открывает следующую.
- **Прогресс** – сохраняется для каждого пользователя в VK Storage (ключ `course_progress_<course>`). Внутри хранятся статусы видео и статей.
- **Кнопка «Сделано! Перейти к следующему»** – отмечает видеоурок как завершённый, проверяет, прочитаны ли все статьи (если есть), и переходит к следующему уроку.
- **Сброс прогресса** – кнопка «Начать обучение сначала» очищает все статусы текущего курса.
- **Вступление в группу** – кнопка для подписки на сообщество «Курсы IT для системных администраторов» (ID `193665099`) с проверкой членства через `VKWebAppGetGroupInfo`.
- **Интеграция с VK** – отображает аватар и имя пользователя, если запущено внутри VK Mini App.
- **Отладка** – переключаемая панель с логами, дублируется в консоль.
- **Яндекс.Метрика** – отслеживание событий (открытие каждого урока).

## 🛠 Технологии

- **HTML5, CSS3, JavaScript** (без фреймворков)
- **VK Bridge** – для работы внутри VK Mini App (авторизация, хранилище, информация о пользователе, работа с группами)
- **VK Storage** – сохранение прогресса пользователя
- **Яндекс.Метрика** (счётчик `110303584`)

## 🚀 Установка и запуск

Проект статический – все файлы лежат в одной структуре. Для запуска достаточно:

1. Скачать или склонировать репозиторий.
2. Открыть `index.html` в браузере (или через локальный сервер, например, `python -m http.server`).

```bash
git clone <url-репозитория>
cd <папка-проекта>
# Открыть index.html в браузере
```

Для корректной работы `fetch` с JSON-файлами рекомендуется использовать локальный сервер (не `file://`).

## 📁 Структура проекта

```
project/
├── index.html                # Главная страница (разметка)
├── style.css                 # Все стили
├── app.js                    # Движок приложения (логика, VK Bridge, работа с хранилищем)
└── data/                     # Данные курсов
    └── linux-console/        # Папка курса (идентификатор)
        ├── course.json       # Метаданные курса + список уроков
        └── lessons/          # Подпапка с уроками
            ├── 1.json        # Урок 1 (видео + 9 статей)
            ├── 2.json
            ├── ...
            └── 10.json
```

Каждый файл урока содержит массивы `videos`, `articles` и `tasks` (заготовка для будущего расширения). В первом уроке уже добавлены 9 статей.

## ⚙️ Настройка для VK Mini App

1. Зарегистрируйте приложение в [VK Admin](https://vk.com/apps?act=manage).
2. Укажите **URL** для запуска (например, `https://ваш-хост/index.html`).
3. В `app.js` найдите константу `GROUP_ID = 193665099` – она соответствует ID вашего сообщества. При необходимости замените на свой.
4. Убедитесь, что в коде указан корректный `owner_id` для видео (в коде используется `-193665099`, это ID группы, где размещены видео).
5. Для работы VK Bridge приложение должно запускаться внутри официального клиента VK (мобильного или веб-версии VK Mini Apps).

## 📖 Использование

1. **Главный экран** – список уроков с эмодзи и статусами.
2. **Выбор урока** – клик по строке открывает видео и список статей (если они есть).
3. **Просмотр видео** – видео запускается автоматически. Кнопка «Назад к урокам» возвращает в список.
4. **Работа со статьями** – список статей отображается под видео. Клик по статье открывает её содержимое. Кнопка «Следующая статья» позволяет последовательно изучать материал.
5. **Завершение урока** – кнопка «Сделано! Перейти к следующему» помечает урок как пройденный (видео – `done`, статьи проверяются на `read`). Если все статьи не прочитаны, появится запрос подтверждения.
6. **Сброс прогресса** – кнопка «Начать обучение сначала» очищает все статусы курса.
7. **Вступление в группу** – кнопка под именем пользователя позволяет подписаться на сообщество, чтобы получать новости о вебинарах и закрытом контенте.

## 🐞 Отладка

- Нажмите на текст **«Версия X.X.X»** внизу страницы – появится панель с логами.
- Также можно добавить параметр `?debug=true` в URL, чтобы панель была видна сразу.
- Все логи дублируются в консоль браузера.

## 📊 Метрика

В приложение встроен счётчик Яндекс.Метрики (ID `110303584`). При клике на каждый урок отправляется цель `step1` … `step10`. Вы можете заменить ID на свой или удалить блок с метрикой, если он не нужен.

## 📝 Примечания

- Видео доступны только при подключении к интернету (встраиваются через iframe).
- Для корректной работы внутри VK требуется установленное приложение VK или браузер с поддержкой VK Bridge.
- Весь код написан с учётом мобильных устройств (адаптивная вёрстка).
- Версия приложения вынесена в константу `APP_VERSION` в `app.js` – обновляйте её в одном месте.
